这个目录里的报告**全部由 [`samples/`](../samples) 下的合成数据生成**，
不是任何人的真实聊天记录。双击即开。

| 文件 | 分数与结论 |
|---|---|
| [`report-cooling.html`](report-cooling.html) | 从热到冷的 203 天 → **58 / 100 · 有点平淡了** |
| [`report-warm.html`](report-warm.html) | 互相投入的 29 天 → 64 / 100（样本偏少，已收缩） |
| [`report-too-short.html`](report-too-short.html) | 只有 5 条消息 → **样本不足，无法给结论**（8 个维度全标 N/A） |
| `report-cooling.json` | 机器可读的完整结果 |

最值得看的两份：**`report-cooling.html`** 是完整示例，一眼能看出
「回复还行、但称呼在消失、收尾全是他、情绪在变冷」这条线；
**`report-too-short.html`** 展示产品里最重要的一道闸门——
样本不够时**明确说不知道**，而不是编一个数字。

## 看报告时留意这几处

报告一页一页往下翻（左侧导航 14 页，滚轮或方向键翻页）：

| 页 | 看什么 |
|---|---|
| 1 · 结论 | 仪表盘、等级、一句话结论，以及「这个分数有多可信？」。样本不足时这里会出现黄色横幅 |
| 2 · 量化指标 | 每项都附**计算口径与数据来源**，可自行复核 |
| 5–7 · 热力图 / 词云 / 画像 | 颜色与字号都有明确编码，图下方写了口径 |
| 10 · 维度明细 | 样本不足的维度标 `N/A` 并写明「没有参与打分」，**不会被当成 0 分** |
| 12 · 原话与证据 | 每一句都来自文件、未改写 |
| 13 · 分数怎么算 | 完整权重与贡献分账，可逐条追问「这 58 分怎么来的」 |
| 14 · 结尾 | 分档安慰文案 + 一句从这份记录里长出来的个性化文案 |

## 自己重新生成

```bash
python -m loves_me_not analyze "samples/demo_two_block_cooling.txt" \
    --me "我" --peer "阿澈" \
    -o demo/report-cooling.html --json demo/report-cooling.json
```

加 `--redact` 可试脱敏；合成数据里没有敏感串，所以输出与不加时一致。

**这些不是真实记录。** 想分析自己的聊天记录，请按
[README](../README.md#-使用) 导出后在本地运行。
