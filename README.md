# 🌼 loves-me-not —— TA 到底爱不爱我

> 撕开聊天记录的花瓣，看看 TA 爱不爱你。
>
> 导入微信 / QQ 导出的纯文本聊天记录，在**本机**算出一个 0–100 的「情感投入指数」，
> 生成一份可以直接发小红书的**单文件 HTML 可视化报告**。

---

## ⚠️ 先读这一段：这是什么，这不是什么

| | |
|---|---|
| **它是** | 一个「娱乐 + 自我反思」工具。用统计学规律把你已经感觉到的相处模式，画成看得见的图。 |
| **它不是** | 关系裁判，也不是读心术。它不知道对方在想什么，它只数得清谁先开口、谁回得快、谁在收尾。 |
| **它是** | 全本地运行。聊天记录不出你的设备，不上传、不联网、不调用任何云端 AI。 |
| **它不是** | 微信数据库解密工具。见下方「法律与隐私红线」。 |

> 本报告基于统计学规律生成，仅供娱乐与自我反思，不代表任何一方的真实情感，
> 重大情感决策请咨询线下专业人士。

**分数低不等于他不爱你，分数高也不等于你们会一直在一起。**
一段关系里的沉默，可能是冷淡，也可能是他那天加班到十一点、手机没电、或者他本来就不太会说话。
工具只能看见文字，看不见人。

## 🚨 法律与隐私红线（请务必读完）

**1. 本项目不读取微信数据库，不绕过微信安全机制。**
它只接受**你自己用导出工具导出的文本/CSV 文件**（例如留痕 MemoTrace 的导出结果）。
微信官方已明确打击通过代码注入或提示词注入获取聊天记录的行为——本项目**不内置**、也**永不会内置**任何解密微信数据库的功能。

**2. 聊天记录涉及双方的隐私。**
用量分析别人的聊天记录，本身是有伦理灰度的事。请确认：

- 你已获得对话参与者的授权，或这些记录是你自己的；
- 你只在本地处理，不把原始记录上传到任何网盘 / 在线服务 / 公开 demo；
- 不要用它去跟踪、监视、控制任何人。

**3. 默认全本地。**
`data/` 与 `out/` 已在 `.gitignore` 中，你的真实聊天记录不会被提交进版本库。
解析、计算、绘图全部在本机内存中完成，**运行过程中没有任何网络请求**。

## 🚀 快速开始

无需安装任何第三方依赖，只需要 Python 3.9+（纯标准库实现）。

```bash
# 1. 分析一份聊天记录，生成 HTML 报告
python -m loves_me_not analyze "path/to/chat.txt" --me "我的昵称" -o out/report.html

# 2. 如果导出文件里有两个以上说话人，或用昵称无法确定「我」
python -m loves_me_not analyze "path/to/chat.csv" --me "阿澈" --format csv

# 3. 先只看解析结果，确认发言人识别对不对
python -m loves_me_not inspect "path/to/chat.txt"

# 4. 输出机器可读的 JSON（便于二次开发）
python -m loves_me_not analyze "path/to/chat.txt" --me "阿澈" --json out/result.json
```

Windows 上如果 `python` 不可用，试 `py -m loves_me_not ...`。

## 📥 支持的输入格式

### 微信（推荐：留痕 MemoTrace 导出的 CSV）

留痕导出的 CSV 通常长这样（列名顺序可能不同，本项目按列名模糊匹配）：

```csv
localId,Time,Sender,Content
1,2023-04-01 21:33:02,阿澈,到家了跟我说一声
2,2023-04-01 21:35:11,我,到啦
```

也支持中文表头 / 无表头：

```csv
时间,发送者,内容
2023-04-01 21:33:02,阿澈,到家了跟我说一声
```

### 微信 / QQ 文本导出（txt / log）

```text
2023-04-01 21:33:02 阿澈
到家了跟我说一声

2023-04-01 21:35:11 我
到啦
```

```text
2023-04-01 21:33:02 阿澈(12345678)
到家了跟我说一声
```

QQ 导出常见的方括号格式也支持：

```text
[2023-04-01 21:33:02] 阿澈
到家了跟我说一声
```

### 解析器会容错处理

- **多种时间戳**：`2023-04-01 21:33:02`、`2023/4/1 21:33`、`2023年4月1日 21:33`、`[21:33:02]`（无日期时按顺序推断日期）、时间戳与昵称在任意一侧
- **多行消息**：昵称行之后的连续行自动并入同一条消息
- **系统消息**：`撤回了一条消息`、`加入了群聊`、`[图片]`、`[表情]` 等自动识别并单独标记（不计入字数统计）
- **群聊**：说话人超过两个时自动降级为「取你与互动最多的那个人」，并在报告中提示
- **BOM / GBK / UTF-8**：自动探测编码，不会因为编码问题整份文件读不出来

> 解析完建议先跑一次 `inspect` 子命令，确认说话人识别无误再看分数——**输入错了，分数就毫无意义**。

## 📊 八个分析维度

所有维度都以**双方对比**的方式呈现：差距（不对称性）往往比绝对值更能说明问题。

| 维度 | 怎么算 | 心理含义 |
|---|---|---|
| **回复间隔与响应速度** | 每次回复相对上一条对方消息的间隔；取中位数与均值、5 分钟内回复率、超过 1 小时才回的比例 | 谁在秒回，谁总在「稍后」 |
| **主动发起对话次数** | 每日首条消息归属 + 静默 ≥6 小时后的「冷启动」由谁开启 + 连续消息段归属 | 谁更在意这段关系 |
| **平均字数** | 每条消息字符数、长短消息比例；同时给「实质性消息」（≥6 字、非纯表情）口径，避免被「嗯」「哈哈」拉平 | 一方是否在敷衍 |
| **提问与追问比例** | 含疑问词或问号的消息占比 + 提问后 10 分钟内继续追问的比例 | 是「想了解你」还是「懒得接话」 |
| **称呼与表情使用** | 亲昵称呼（宝宝/亲爱的/老婆…）词频、表情与表情包占比、称呼随时间的变化趋势 | 关系温度的语言痕迹 |
| **谁在结束对话** | 谁发出最后一条消息后对话结束、谁在对方提问后「不接话」直接离开 | 谁先转身 |
| **深夜及特定时段活跃度** | 23:00–03:00 消息占比、双方各自的活跃时段分布 | 情感浓度（好或坏都算） |
| **情绪倾向随时间变化** | 基于情感词典的逐条极性打分，按时间分段看均分与趋势方向 | 是越来越甜，还是越来越客气 |

**情感词典是本地的、可审计的**（见 `loves_me_not/lexicon.py`），不依赖任何在线模型。
它不完美——反讽、网络梗、方言都会误判。所以报告里每一个结论都附上**原始聊天片段**，让你自己复核。

## 🧮 打分模型（可解释，不黑箱）

- 每个维度先算出若干**子指标**，各自映射到 0–100；子指标加权得到维度分，维度分再加权得到总分。
- **权重随「TA 视角 / 我的视角」切换**：判断「TA 爱不爱我」时，看的是 TA 的回复速度、TA 的主动性、TA 的投入度。
- **样本不足会降级而不是猜**：
  - 样本量低于阈值 → 总分区间收窄，报告顶部直接标注**「样本不足」**并拒绝给强结论；
  - 某个维度无法计算（例如全程没出现过任何亲昵称呼）→ 该维度标记为 `N/A` 并从加权中剔除，权重重新归一化，**绝不当成 0 分**；
  - 聊天记录里没有任何内容 → 直接报错退出，**不生成任何虚构报告**。
- 所有中间量都会写进报告和 JSON，你可以逐条追问「这 47 分是怎么来的」。

**等级结论**

| 分数 | 等级 | 说明 |
|---|---|---|
| 85–100 | 还是很爱你 | 主动、秒回、话题不断 |
| 70–84 | 热度在线 | 整体稳定，偶有降温 |
| 55–69 | 有点平淡了 | 还在，但节奏放慢了 |
| 40–54 | 已经在变淡 | 多项指标偏向单方面 |
| 20–39 | 基本没戏 | 长期单方面投入，回应稀薄 |
| 0–19 | 几乎可以放手了 | 数据上看这段关系已经停摆 |

## 📄 报告长什么样

单文件 HTML，双击即开，没有任何外部依赖（不联网、不加载 CDN），手机上也排得下：

1. **顶部大字直白给结论** —— 一眼看到分数和等级，不用翻
2. **得分仪表盘** —— 总分 + 双方各自的投入度对比
3. **八维雷达图** —— 哪几项拖了后腿，一眼看出
4. **互动趋势折线图** —— 消息量 / 主动发起 / 情感倾向随时间的走势
5. **关键数据卡片** —— 中位回复时延、主动发起占比、平均字数比…
6. **典型原话摘录** —— 支撑结论的**真实片段**（可脱敏），自己复核
7. **温柔克制的收尾** —— 承认人心会变，鼓励你向前看，不说教、不指责
8. **固定的数据来源与免责声明**

## 🔐 隐私设计

- 全流程**零网络请求**（代码中不存在任何网络调用）
- 报告内**只展示你聊天的必要片段**；`--redact` 可对昵称、手机号、身份证、地址、微信号做打码
- 生成路径与中间产物均在你本机；`data/`、`out/` 不入库
- 不做「分析任何目标人物」的在线 demo，避免变成跟踪工具
